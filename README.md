# AI Code Review Playbook

This repository is a practical guide and self-audit tool for evaluating AI-generated code. 

It contains:
- `REVIEW_RUBRIC.md`: The criteria used to audit code (Security, Concurrency, Performance).
- `bad_code_examples/`: Real examples of vulnerable code generated by LLMs.
- `my_reviews/`: Detailed explanations of the bugs and how to fix them.

This is the exact methodology I use when evaluating code for AI platforms (Mercor, Outlier).
